## BMKG station rainfall (RR), profiled 2026-10-06

Script: `tools/explore_bmkg_profile.py` (exploratory; sentinel values 8888 and 9999 and
negative values excluded before counting valid days).

| # | Finding |
|---|---|
| F1 | **180 stations, 180 unique WMO IDs.** Records start 1980-2020 and end 2013-2021. |
| F2 | **Coverage is uneven.** Valid RR days per station: median 9,601; 10th percentile 1,367; 5 stations under 365 days; 46 under 3,650 (10 years). Stasiun Geofisika Balikpapan has **zero** valid RR days. |
| F3 | **The daily network changes a lot.** Median stations reporting per day: 40 (1980), 87 (1990), 101 (2000), 138 (2010), 92 (2013), 86 (2015), 131 (2021). No year reaches 180. |
| F4 | **8888 occurs 116,762 times across 173 stations; no 9999 in RR.** CORRECTED 2026-10-07: 8888 is *not* a missing code. The workbook legend defines `8888: data tidak terukur` (not measurable) and `9999: Tidak Ada Data (tidak dilakukan pengukuran)` (no data, no measurement). For RR, 8888 marks an observed day with unmeasurably small rain (trace): on 97% of 8888 days in 44 sampled workbooks the station reported Tx, and co-located series show 0 mm on 90-100% of those days at many sites (grid-code-reviewer, 2026-10-07). |
| F5 | **Station spacing.** Nearest-neighbour distance quantiles (km), min / 10 / 25 / 50 / 75 / 90 / max: 0.0 / 4.4 / 12.6 / 32.1 / 93.4 / 159.5 / 302.5. Inside a rough Java box (105-115.5E, 9-5.5S): 35 stations, median NN 22.2 km; outside: median 46.0 km. |
| F6 | **QC candidates already visible.** Two co-located pairs: Minahasa Utara / Sam Ratulangi (0.016 km apart) and Semarang / Ahmad Yani (0.95 km). Max daily RR 1,965.5 mm at Banyuwangi and 888.0 mm at Palu (888.0 may be a truncated 8888). Both need `/qc` before any use. |

Caveats: the Java box is a rectangle, not a coastline, so its count is approximate.
"Stations reporting per day" counts any valid RR value, before QC.
